This one's special to me. TeleporterDash was my first ever GitHub project, my first game, the thing that got me into open source in the first place. I was obsessed with Geometry Dash and thought, "What if I made something inspired by it but with its own identity?" Not a clone. A real game that could stand on its own.

The core twist is teleportation. Instead of just dashing forward, you teleport through levels with precise timing. Add double jumps on top of that and suddenly the level design space opens up in ways Geometry Dash never touches. You're not just avoiding obstacles, you're thinking in two dimensions about where you can go to next.

## What's In It

Built entirely in HTML, CSS, and JavaScript. No frameworks, no engines, just raw web tech. The game has a level progression system, immersive soundtrack (originally Geometry Dash music, with plans for original tracks), and a built-in level editor where you can design your own challenges and share them online with the community.

The level editor was the ambitious part. I wanted players to create and share levels without needing to install anything. You build a level in the browser, save it, and share the link. Other people play your level in their browser. It was my first taste of building tools for other people to be creative with.

## The Open Source Angle

I designed this from the ground up to be open source. Not "I'll throw the code on GitHub after I'm done" but "the code is part of the project." Every mechanic, every level format decision, every UI choice was made with the assumption that other people would read the code, fork it, make their own versions. That philosophy stuck with me and shaped everything I've built since.

## Where It Lives

It's on GitHub and on itch.io. The code is messy in the way first projects always are, but it works and people have played it. That's more than I expected when I started.

Check it out at [nellowtcs.itch.io/teleporterdash](https://nellowtcs.itch.io/teleporterdash).
